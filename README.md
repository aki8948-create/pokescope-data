# PokeScope 大会データ更新

Limitless TCGの公開Pocket大会結果から、最新と前回のパック期間、参加30人以上の大会だけを取得します。非公式ファンツールです。カード画像は配信しません。

## 更新
GitHub Actionsの標準Ubuntu環境で毎日日本時間6:17頃に実行します。混雑で遅れる場合があります。AI・有料ランナー・有料APIは使用しません。

取得・カード照合に失敗した日は公開せず、前回の正常な配信を保持します。新規大会のルールが確認できない場合、通常ルールに含めません。

## 容量
データをGit履歴に毎日保存しません。配信データは最大50MB、更新途中の配信用ファイルは1日保持、永続キャッシュは使いません。古いパック期間の大会は次回成功時に配信対象から外します。有料プラン・支払方法の登録は不要です。

## 新パック発売時
packs.jsonのcurrentをpreviousへ移し、新パックの名前と日本時間の開始日をcurrentへ登録してください。発売日の自動登録と新カードの日本語名登録は未実装です。現時点のpreviousの開始日は既存プロトタイプに合わせた2026-08-12で、パックの実際の発売日を意味しません。

## 注意
GitHubは公開リポジトリに60日間活動がない場合、定期実行を停止する場合があります。新パック設定時にActionsも確認してください。失敗通知はGitHubの通知設定に従います。最後の取得時刻で鮮度を確認してください。
